# Version Control with Git

## Objective
Demonstrate Git version control operations including:
- Repository setup
- Branch creation
- Merge conflict resolution

---

## Tools Used
- Git
- GitHub
- VS Code

---

## Steps Performed

### 1. Initialized Git Repository

```bash
git init
```

### 2. Created Branches

```bash
git branch feature1
git branch feature2
```

### 3. Simulated Merge Conflict

Different changes were made in two branches.

### 4. Resolved Merge Conflict

Conflict markers were removed manually and merged successfully.

---

## Git Commands Used

 ```bash
git init
git add .
git commit -m "message"
git branch
git checkout
git merge
git push
```

---

## Outcome

Successfully demonstrated:
- Git workflow
- Branching
- Merge conflict resolution
- GitHub integration
